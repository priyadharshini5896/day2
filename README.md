# Sales Data Visualization with Power BI

This project showcases an interactive Power BI dashboard built using a sales dataset. The visualization highlights key business metrics and trends, enabling data-driven insights into customer behavior, product performance, and regional sales distribution.


# Dataset Overview

The dataset contains anonymized sales transactions, including:
-  Date and time of order
-  Product details (category, item ID)
-  Customer demographics (age, gender, region, city)
-  Payment methods
-  Transaction amounts, discounts, and totals


#  Key Features

#  Interactive Dashboard Components
- Sales Trend Over Time — Track total sales by month/year.
- Sales by Region & City — Visualize geographic performance on maps.
- **Top Categories & Items — Identify best-selling products.
- Customer Demographics** — Breakdown by gender, age group, and region.
- Discount Analysis — Assess the impact of discounts on sales.
- Payment Method Distribution — See how customers prefer to pay.
- Quantity vs Value Bubble Chart — Analyze order patterns and efficiency.
